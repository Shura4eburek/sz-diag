# Живой чек-лист: SzDiag Desk, часть 4 — `ask_peer` и похожие СЗ (2026-09-25)

- [ ] Две онлайн-СЗ: через пару опросов под номером появилась строка железа (CPU · плата · память), совпадает с `hw-fingerprint.ps1`.
- [ ] Две одинаковые сборки → у обеих `≈<сосед>`, подсказка перечисляет совпавшее; разные сборки — бейджа нет.
- [ ] В сессии A: «спроси соседа, что уже нашли» → `ask_peer` без live, в ленте A карточка `ask_peer` с выжимкой; карточки разрешения нет.
- [ ] «Спроси соседа живьём, какой BIOS» → в ленте B `💬 от A: …`, точка B фиолетовая, на обеих карточках `💬`; ответ B — в карточке инструмента у A.
- [ ] «■» в A, пока B занят своим ходом → вопрос снят; B после своего хода его не получает.
- [ ] «Открыть в терминале» у B, затем живой вопрос из A → ошибка «сессия соседа не запущена», Desk не поднял B вторым писателем.
- [ ] Встречный вопрос из B в A, пока A ждёт → в B ошибка «сама ждёт ответа соседа».
- [ ] `peers`/`ask_peer` в режиме `auto` не просят разрешения; если просят — `--allowedTools` не подхватился (записать в бэклог).
- [ ] Под OCCT на одной из СЗ профиль не снимается каждые 2 с: в `logs\hub-*.log` exec профиля — не чаще раза в 5 минут.
