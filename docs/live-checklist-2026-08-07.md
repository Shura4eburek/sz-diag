## 2. Диагностика (10 мин)

- [ ] `szcli diag run <СЗ> reboots whea livekernel reliability storage`
- [ ] В `diag.md` проверить:
  - [ ] секция **«История сбоев»** отрабатывает и печатает `CrashDumpEnabled`/`AutoReboot`/
        `MEMORY.DMP`, а не `ошибка: код 1` (п.74);
  - [ ] **reboots**: блок «klassifikaciya» — сколько hard-off, сколько кнопки, сколько BSOD;
        «First hard-off … after OS install» считается только по обрывам (п.93);
  - [ ] **whea**: если есть события Id=1 — заполнены `kanal` (MCE/CMC/PCIe) и `severity` из
        бинарной записи CPER, сводка `by CPER` не пустая (п.68);
  - [ ] **livekernel**: `P1` печатается как `0x124 WHEA_UNCORRECTABLE_ERROR`, есть свод
        «by code» и разбор пачек с пометкой «artefakt zakrytiya 3D-prilozheniya» (п.69/94);
  - [ ] в начале `reboots`/`whea` — блок «Okno etogo zheleza» (п.92). На обычной машине
        ожидается «OS na etom zheleze s …»; на сервисном USB-образе — предупреждение про
        переносную ОС и отброшенные чужие события.

**Отдельно, если есть под рукой сервисный USB-образ:** загрузить им машину и повторить
`diag run <СЗ> reboots whea` — это единственный способ проверить п.92 по-настоящему.

- [ ] **`szcli agent set <СЗ> WatchdogHours=12`** — ожидание: «было …, стало 12» и
      «watchdog перевзведён на <дата>» (п.86).
- [ ] Дождаться срабатывания watchdog при живом агенте (или временно поставить

      **«агент жив (heartbeat N мин назад) — доступ НЕ трогаю, перевзвожу watchdog»** (п.85),

- [ ] **`szcli agent restart <СЗ>`** — ожидание: «перезапуск поставлен», через ~1 минуту СЗ
      снова online с открытым доступом; машина ни разу не осталась без канала (п.83).
- [ ] На клиентской машине **на рабочем столе** — ярлык «Закрыть доступ SzDiag (СЗ …)».
      Запустить его: UAC → откат → доступ снят (п.87).
- [ ] После отката: `szcli list` — СЗ **не должна** висеть «online · готов» (п.81);
      агент завершается сам, СЗ уходит в offline.

## Известные ограничения этой сборки (проверять не нужно, знаем)

- `szcli list` **не** показывает отдельно, жив ли sshd — только heartbeat (п.95, хвост).
- Горячего перечитывания `appsettings.json` внутри агента нет: конфиг меняется командой
  `szcli agent set` (п.86, частично).
- GPU-колонки наблюдателя заполняются только через `nvidia-smi` — на AMD они пустые (п.80).
- Флаг троттлинга GPU в CSV не пишется (п.80, хвост).
- Разбор MCA-банков внутри CPER не делается — только severity/канал/секции/APIC (п.68, хвост).
