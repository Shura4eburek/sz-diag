## Exec (главный кластер)

- [ ] `szcli diag run <СЗ> whea` на машине с событиями WHEA печатает сводку `by CPER`,
  а не «имя файла слишком длинное» (п.101/196 — файл-фоллбэк PowerShellRunner).
- [ ] `szcli exec <СЗ> -f tools\recipes\client\...` с `param(...)` работает и не печатает
  CommandNotFoundException (п.102/189).
- [ ] `szcli exec <СЗ> "exit 7"; $LASTEXITCODE` → 7; «агент занят» → 3; таймаут → 4 (п.103).
- [ ] `szcli exec <СЗ> --jobs` показывает фоновые задачи; `--cancel <jobId>` снимает задачу —
  проверить **под полной нагрузкой** (канал статуса должен пройти) и после рестарта агента
  (фоллбэк поиска по jobId + taskkill /T) (п.134/172/176).
- [ ] Рецепт с опечаткой через `--detach` → `--result` печатает «ошибка скрипта: …» с текстом
  parse-ошибки, а не «завершена (exit 1), вывода 0 б» (п.177).
- [ ] Длинный вывод (chkdsk) приходит с головой И хвостом + «пропущено N символов» (п.181).

  порядке аргументов.
