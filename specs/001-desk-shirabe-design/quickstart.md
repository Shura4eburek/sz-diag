# Quickstart: проверка редизайна

## Автотесты

```powershell
dotnet test tests/SzDiag.Desk.Tests      # все зелёные; ThemeTests — токены, шрифты, нет hex в Views
```

## Глазами

```powershell
dotnet run --project src/SzDiag.Desk
```

Сверить с карточкой MainWindow артефакта Shirabe (https://claude.ai/artifact/TYJjNu1apzCZjcvczfoPxy):

1. Рама `#131417`, три острова со скруглением 10 и зазором; тулбар 40, статус-бар 24.
2. Тулбар: перетаскивание, двойной клик — развернуть/восстановить, иконка restore в
   развёрнутом окне, «Закрыть» краснеет при наведении.
3. Список СЗ: «Заявки · N», бейджи иконками без эмодзи, выбор с фокусом/без.
4. Чат: шапка, реплики оператора на сером, ToolCall моно-шрифтом, карточка разрешения
   с «Ждёт подтверждения», пульс точки во время хода.
5. Инспектор: 7 вкладок высотой 36 с акцентным подчёркиванием, пустые состояния.
6. `szcli pull` — нижняя панель передач с прогрессом; остановить hub — статус-бар пишет
   словом, данные «на ЧЧ:ММ».
7. Окно 900×520 и масштаб 150% — ничего не наезжает и не размывается.
