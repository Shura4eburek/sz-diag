# sz-diag

Система удалённой диагностики клиентских машин в сервисном центре по номеру СЗ
(сервисной заявки).

Claude работает на чистом сервисном боксе и дотягивается до клиентских машин по SSH,
не устанавливаясь на них и не оставляя следов. Агент на клиенте открывает доступ и
регистрирует машину под номером СЗ; центральный CLI показывает, какие СЗ онлайн.

**Статус:** дизайн Фазы 1 (агент + реестр/CLI + структура базы знаний).
См. [docs/vision.md](docs/vision.md).
